RP Forge's own code does not live in this folder. These are shared, freely embeddable libraries that
roleplay addons use to talk to each other. They are included unmodified, each under its own terms.

LibMSP
    The Mary Sue Protocol: the profile format shared by Total RP 3, MyRolePlay, XRP and others.
    Authors: "Etarna Moonshyne", Morgane "Ellypse" Parize, Justin Snelgrove.
    Licence: Creative Commons Zero (CC0 1.0), see LibMSP/LICENSE.txt.

Chomp
    Splits, sends and joins long addon messages for LibMSP.
    Copyright Justin Snelgrove. Licence: see Chomp/LICENSE.txt (permission to use, copy, modify and
    distribute, provided the copyright and permission notice appear in all copies).

ChatThrottleLib
    Keeps addon messages under the game's limits. By Mikk. Published as a fully embeddable library.

CallbackHandler-1.0
    Event callbacks, used by Chomp. From the Ace3 library collection (Ace3 Development Team).

LibStub
    Library version loader. Placed in the public domain by its authors.
